# cheburek-core

The core library for Cheburek – a text generation bot.

See [Discord](https://github.com/cheburek-bot/cheburek) and [Telegram](https://github.com/cheburek-bot/cheburek-telegram) bots sources.

Cheburek uses Markov chains to store words from users. Read my [post](https://zorreth.com/blog/markov-chains/) to learn more about it.
